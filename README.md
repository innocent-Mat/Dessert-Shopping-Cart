# Dessert Shopping Cart

A simple and interactive shopping cart web application built with HTML, CSS, and JavaScript. Users can browse a selection of desserts, add items to their cart, view the total number of items, calculate taxes and totals, and clear the cart with a confirmation prompt.

## Features

- 🍰 Display a variety of dessert products
- 🛒 Add desserts to the shopping cart
- 🔢 Automatically update the total number of items
- 📦 Track the quantity of each product in the cart
- 💰 Calculate subtotal, taxes, and grand total
- 👁️ Show or hide the shopping cart
- 🗑️ Clear the cart with a confirmation dialog
- ⚠️ Alert users when attempting to clear an empty cart
- 📱 Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## How It Works

1. Browse the list of available desserts.
2. Click **Add to Cart** to add a dessert.
3. The cart updates automatically:
   - Total number of items
   - Quantity of each dessert
   - Subtotal
   - Taxes
   - Total cost
4. Use the **Show/Hide Cart** button to toggle the cart's visibility.
5. Click **Clear Cart** to remove all items after confirming the action.
